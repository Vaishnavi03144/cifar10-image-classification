# cifar10-image-classification

CIFAR-10 image classification using CNN with TensorFlow/Keras.
## Project Overview
This project builds a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset into 10 different categories.
## Dataset
The CIFAR-10 dataset contains 60,000 color images of size 32x32 divided into 10 classes such as:
- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck
## Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab
- NumPy
- Matplotlib
## Model
The model uses a Convolutional Neural Network with:
- Convolution layers
- MaxPooling layers
- Dense layers
- Dropout for regularization
## Results
The model achieves around 70% accuracy after training.
## How to Run
1. Open the notebook in Google Colab
2. Install required libraries
3. Run all cells to train the model
